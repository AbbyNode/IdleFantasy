# Architecture Documentation

This directory contains technical documentation for the Idle Fantasy codebase. Intended for skilled developers contributing to the project.

## Files

- **[overview.md](overview.md)** - High-level architecture and app structure
- **[data-layer.md](data-layer.md)** - Database schema, entities, and data flow
- **[business-logic.md](business-logic.md)** - Game simulators and core repositories
- **[ui-architecture.md](ui-architecture.md)** - Compose screens and ViewModels
- **[background-services.md](background-services.md)** - Alarms, notifications, background workers
- **[flaws.md](flaws.md)** - Known architectural issues and anti-patterns
- **[testing.md](testing.md)** - Testing patterns and guidance

## Quick Start

For a typical contribution, start with **[overview.md](overview.md)** to understand the overall structure, then dive into the specific layers based on what you're changing.
